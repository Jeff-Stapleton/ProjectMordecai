## scaling_rules

| Item | Value |
| --- | --- |
| Scaling System | Use Effective Mod instead of raw Mod for all attribute scaling. |
| Band 1 | Mods 1–5 count at 100% value. |
| Band 2 | Mods 6–10 count at 70% value. |
| Band 3 | Mods 11–15 count at 45% value. |
| Band 4 | Mods 16+ count at 25% value. |
| Formula | Effective Mod = min(Mod,5) + max(min(Mod-5,5),0)*0.7 + max(min(Mod-10,5),0)*0.45 + max(Mod-15,0)*0.25 |
| Example (Mod 12) | Effective Mod = 5 + 3.5 + 0.9 = 9.4 |
| Example STR 12 | Physical Dmg = 3.0% x 9.4 = 28.2%; Armor Penetration = 1.5% x 9.4 = 14.1% |
| Example DEX 12 | Attack Speed = 1.5% x 9.4 = 14.1%; Physical Crit Chance = 0.75% x 9.4 = 7.05% |
| Balancing Note | If penetration or resistance proves too volatile in testing, convert those two families to rating instead of raw %. |
