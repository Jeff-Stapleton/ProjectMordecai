## Bindings

| Action | Category | Controller | Keyboard | Mouse | Notes |
| --- | --- | --- | --- | --- | --- |
| Move | Movement | Left Stick | W/A/S/D |  | 360° analog vs digital. Movement always available. |

| Heavy / Charged Attack | Combat | RT (hold) | Left Mouse (hold) | Hold Left Click | Charge time depends on weapon. |

| Parry | Combat | LT + RT | Right Mouse + Left Mouse (timed) | RClick + LClick | Timed click while blocking; high risk/high reward. |
| Use Skill A | Skills | RB (tap) | Q (tap) |  | Executes equipped Skill A. |

## Controller Summary

| Group | Mapping |
| --- | --- |
| Movement | Left Stick = Move \| L3 = Sprint (toggle) |
| Camera/Aim | Right Stick = Look/Aim \| R3 = Sneak (toggle) |
| Combat | RT = Light (tap) / Heavy (hold) \| LT = Block \| LT+RT = Parry |
| Skills | RB = Skill A (tap) / Select A (hold radial) \| LB = Skill B (tap) / Select B (hold radial) |
| Actions | A = Jump \| B = Dodge \| X = Interact \| Y = Throw (tap) / Weapon Swap (hold) |
| Items | D-pad Down/Left/Up/Right = Item A/B/C/D |
| System | Start = Menu \| View/Select = Map/Objective |

## KBM Notes

| Topic | Recommendation |
| --- | --- |
| Aim Model | Mouse aims facing direction. No target lock. Attacks/spells go toward aim direction. |
| Parry | Parry is performed by timing LClick while holding RClick (block). Matches LT+RT. |
| Skill Selection | Hold Q/E for Skill A/B selection; use Mouse Wheel or number keys (1–8) while held to choose. |
| Weapon Swap | Tab swaps weapon sets quickly (controller uses Hold Y). |
| Quick Items | 1–4 keys are Item A–D. Consider optional modifier + wheel later if desired. |
