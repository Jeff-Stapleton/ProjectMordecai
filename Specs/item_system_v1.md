# Item System Spec v1

## Item Categories

-   Weapons
-   Armor
-   Trinkets
-   Consumables
-   Upgrade Keys

------------------------------------------------------------------------

## Rarity Tiers

Common Green Blue Purple Red / Gold

Higher tiers introduce: - stronger modifiers - unique abilities

------------------------------------------------------------------------

## Item Modifier Types

StatModifier AbilityModifier ProcEffect PassiveBonus

Example:

Flameblade +15% fire damage Attacks apply Burning

------------------------------------------------------------------------

## Affix System

Affixes modify stats or abilities.

Example affixes:

-   +AttackSpeed
-   +SpellPower
-   +BleedChance
-   +StaminaRegen

Affixes scale with item rarity.
