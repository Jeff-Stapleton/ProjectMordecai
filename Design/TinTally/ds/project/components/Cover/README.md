# Cover

The system's cover: the Tin Tally wordmark on its two-string nameplate, hung over a strip of toy diorama while the rail prints tickets beside it.

It is built only from real parts, using their own classes: the two-string screen nameplate (Tag), a feat medallion (Pyromaniac, `fire` glyph), a `.tt-diorama` floor with props, the "Kills: 7" rail head with three stubbed tickets (TallyRail kinds SKILL UP, ITEM · PURPLE, and a Common slip), and the [I] Inventory hint pill (InteractPrompt). The Tally's counting stands in for the Dungeon Crawler Carl half; the ink-outlined toy island stands in for the Link's Awakening half. It is not a game screen; nothing on it is a layout to copy.
