ItemCard's sibling

The same enamel card, band, grommet, stat strip and effect lines (.tt-itemcard + .tt-spellcard). The band is spell-points with the SP cost as pips; the head carries SpellSlot's 64 px glyph well.

Real data

Costs, cooldowns, timing, targeting, range and movement are the DA_Spell_* values. Cast time = WindupTime + CastTime (when the spell fires). Descriptions are example copy: UMordecaiSpellDataAsset has no Description field yet (TODO(DECISION)).

One device (D5)

Slot keycaps are drawn for keyboard (Q, E, R, 1). Gamepad: LB, RB, none, D-pad Up; Stone Skin has no gamepad button (US-097).

Colour is never alone

Damage type = pill colour + type glyph + word; heal = the heal pill. On enamel every glyph and word is ink; the colour lives in the pill and the well.
